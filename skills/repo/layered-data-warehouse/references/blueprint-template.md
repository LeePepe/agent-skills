## 写蓝图纪律

- **每条设计挂到发现**:分层映射的每一行都能追到 Phase 0 清单里的真实结构,不留凭空建议。
- **grain 优先诚实**:多 grain 事实表 > 一张万能宽表;OBT 只在消费侧且写明理由。
- **SSOT 红线逐个点名**:别泛泛说"复用现有逻辑",要点名具体函数/服务,并在 Gap 表把"重抄"标红旗。
- **止于蓝图**:refine 计划是"要做什么"的清单,不是 SQL/DDL 实现;不在蓝图里写建表脚本。
- **audit 模式产物不同**:已有完整分层的项目,Gap 表列"纪律偏移"(幂等/脱敏/grain 标注),
  而非"该建什么表"。
